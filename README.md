# Онова за клиентите

Simple client, job and money tracking for any small service business, from one person to a small team. Bulgarian UI, phone-first PWA.

## Status

The product design is final. Next come throwaway prototypes, starting with the setup wizard and the "+" new-job flow (see the prototype plan in the design doc).
